# 전체 실험 정리: logit lens가 보여 주는 "중간 층의 영어"는 진짜인가 (2026-11-26 기준)

실험마다 **① 무엇을 기대했고 무엇을 증명하려 했나 → ② 실제 결과(표·그림) → ③ 결론** 순서로 정리했다.
맨 끝의 "말할 수 있는 것 / 말할 수 없는 것" 표에서 주장 강도를 따로 정리했다. 앞선 리뷰에서 과장이라고 지적된 부분(E 0.94→0.38의 Wendler 비교, B 음성 대조, 간섭 ×3.8, placebo 정합성)은 해당 절에 그대로 적었다.

- 자세한 실행 기록: `실험A_진행정리.md`, 이전 종합본: `실험_최종정리.md`
- 원본 표: `results_C/*/report_C.md`, `results_placebo/*/report_placebo.md`, `results_ablate/llama/report_ablate.md`
- 인과 개입 설계(결과 보기 전에 작성): `인과개입_설계.md`

**수치 기준** (따로 적지 않으면)
- 중간 층 ℳ = 상대 깊이 25–75% (Llama 7–21층, EXAONE 8–22층) 평균
- 프롬프트 마지막 토큰, 템플릿 4개 평균, 번역 과제(한→중), 입력어 조건
- 상관·주요 분석은 4개 템플릿 중 3개 이상 맞힌 문항(정답 3/4)
- CI는 95% bootstrap, 단위 nats (1 nat ≈ 확률 2.7배)

## 1. 공통 설정

### 1-1. 질문과 가설

logit lens로 다국어 LLM의 중간 층을 읽으면 영어가 없는 한→중 번역에서도 영어가 보인다(Wendler et al. 2024). **검증 대상은 모델이 아니라 lens다.** 이 영어가 모델이 실제로 쓰는 것인지, lens가 부풀린 것인지 판정한다.

- **가설 ① 평균 성분**: 입력과 무관하게 늘 영어 쪽으로 기우는 공통 성분이 있다 → 평균을 빼고 읽으면(μ_wiki, μ_task) 영어가 줄어야 한다.
- **가설 ② 기저 차이**: 중간 층과 최종 층의 좌표계가 달라서 최종 층 출력층으로 읽으면 잘못 읽힌다 → 좌표계를 맞춘 lens로 읽으면 영어가 줄어야 한다.

### 1-2. 지표

| 지표 | 정의 | 무엇을 보나 |
|---|---|---|
| E | p(라틴) / (p(라틴)+p(한자)+p(한글)) | 영어 '글자' 비중 |
| 언어 질량 | p(라틴)+p(한자)+p(한글) | 작으면 E를 믿을 수 없음 |
| KL | KL(실제 최종 출력 ‖ lens 판독) | lens 충실도, 낮을수록 좋음 |
| spec | log p(영어 단어 \| 관련 입력) − log p(같은 단어 \| 무관 입력) | 개념 특이적 영어 신호. 토큰 기본 빈도가 상쇄됨 |
| 간섭 I | log p(방해어 \| 입력어) − 평균 log p(방해어 \| 대조어 2개). 예: 봄 → 弹簧 | 최종 출력만 씀. lens와 무관한 행동 지표 |
| s_L | 중간 층에서 영어 다의어(spring) log p 최댓값 | lens 영어 점수 |
| r_L | s_L과 I의 부분 Spearman (영어·한국어·방해어 빈도 통제) | 예측 2 |

### 1-3. 데이터와 모델

| 데이터 | 역할 | 규모 | 예 |
|---|---|---|---|
| A | 주 실험. 한국어는 뜻 하나, 영어 번역이 다의어 | 97문항 | 봄 → 春天 / 방해어 弹簧(spring) |
| B | 음성 대조. 한국어 자체가 동음이의어, 두 뜻의 영어는 무관 | 30단어 × 2방향 = 60행 | 배 → 船 / 梨 |
| C | 다의성 없는 일반 단어 + 무관 단어 | 204문항 (분석 194) | 바다 → 海 / 무관 culture |

| 모델 | 층 | ℳ | 입력 | 번역 정답률 (A) |
|---|---|---|---|---|
| Llama-3.2-3B (base) | 28 | 7–21 | 평문 few-shot | 50.5% (3/4 정답 43문항) |
| EXAONE-3.5-2.4B-Instruct | 30 | 8–22 | 대화 형식 | 38.4% (3/4 정답 31문항) |

lens: **logit**(그대로) / **평균 제거**(μ_wiki, μ_task) / **ridge affine**(위키로 h_ℓ → h_L, MSE) / **tuned**(위키로 학습, 최종 출력 분포와의 KL). lens 학습 문장은 위키 ko·zh·en (민감도: ko·zh).

## 2. 실험 1 — lens 충실도: MSE affine은 붕괴, KL tuned가 기준 lens

### 기대한 것
가설 ②를 시험하려면 "기저는 맞추되 판독은 무너지지 않는" lens가 필요하다. 처음 쓴 ridge affine이 그 역할을 할 거라고 기대했다.

### 실제 결과

KL(최종 ‖ lens), ℳ 평균:

| 모델 · 과제 | logit | 평균 제거 μ_wiki | ridge affine (MSE) | **tuned (KL)** |
|---|---|---|---|---|
| Llama 번역 | 9.36 | 9.64 | 9.07 | **7.09** |
| Llama 반복 | 10.56 | 10.66 | 8.14 | **5.87** |
| EXAONE 번역 | 10.93 | 11.19 | 15.59 (logit보다 나쁨) | **8.83** |
| EXAONE 반복 | 12.84 | 12.33 | 16.92 | **11.41** |

affine 붕괴의 증거:

| | EXAONE 15층: '기타'(공백·기호) 질량 | 판독 1위 최빈 토큰 | lens 학습 언어 바꿀 때 E (Llama) |
|---|---|---|---|
| logit | 0.052 | ' chuckled' 1,380번 | — |
| ridge affine | **0.996** | **'\n' 5,696번** | **0.43 → 0.21** (ko·zh·en → ko·zh) |
| tuned | 0.063 | '\n' 1,293번, ' chuckled' 852번, '현', '접' … | 0.380 → 0.380 |

- tuned 위키 검증 KL: Llama 7층 8.99 → 2.46, EXAONE 15층 8.24 → 2.02. 언어 질량 0.90 이상 유지.
- 신뢰도(split-half): I와 lens 점수 모두 0.78–0.99.

### 결론
- **MSE로 은닉 벡터를 맞추는 affine은 lens로 쓸 수 없다.** 입력과 무관하게 평균 벡터(공백·줄바꿈) 쪽으로 무너지고, affine으로 보이는 낮은 E(0.43, 0.20)는 가짜다. 증거로 쓰지 않았다.
- **출력 분포(KL)로 맞추는 tuned lens**는 네 조건 모두에서 가장 충실하고, 학습 언어를 바꿔도 안정적이다. 이후 모든 "보정 lens"는 tuned를 뜻한다.
- 원인 해석(R² 0.46–0.66인 회귀가 평균으로 끌려감)은 그럴듯하지만 직접 검증하지 않았다. `compare_other/affine_check.py`는 다른 분 구현과의 차이(λ 범위, λ 선택 기준 MSE vs KL)를 확인하는 스크립트다.
- 남은 약점: tuned는 30 epoch 안에 완전히 수렴하지 않았고, EXAONE에서는 tuned도 KL 8.8로 크다.

## 3. 실험 2 — 예측 1: 영어 글자 비중 E (가설 ① vs ②)

### 기대한 것
- 가설 ①이 맞다면 평균 제거 lens에서 E가 내려간다.
- 가설 ②가 맞다면 tuned lens에서 E가 내려간다.

### 실제 결과

| E (ℳ 평균) | logit | 평균 제거 μ_wiki / μ_task | **tuned** |
|---|---|---|---|
| Llama A 번역 | 0.94 | 0.95 / 0.95 | **0.38** |
| Llama A 반복 (번역 불필요) | 0.93 | 0.93 / 0.93 | **0.41** |
| Llama B 번역 | 0.94 | 0.95 / 0.96 | **0.39** |
| Llama C 번역 | 0.94 | 0.95 / 0.95 | **0.38** |
| EXAONE A 번역 | 0.67 | 0.67 / 0.70 | **0.55** |
| EXAONE A 반복 | 0.67 | 0.68 / 0.73 | **0.55** |
| EXAONE B 번역 | 0.67 | 0.67 / 0.70 | **0.55** |

같은 은닉 상태를 두 lens로 읽은 예 (Llama 14층):

| lens | 라틴 | 한자 | 한글 | 기타 | 판독 1위 예 |
|---|---|---|---|---|---|
| logit | **0.785** | 0.043 | 0.015 | 0.158 | 'afi', 'anzi', 'onium' (뜻 없는 조각) |
| tuned | 0.116 | **0.843** | 0.003 | 0.038 | '人', '散', '排' |

<img width="1800" height="1290" alt="image" src="https://github.com/user-attachments/assets/f976cc34-b1c0-4a69-96d4-930851349b22" />


### 결론
- **가설 ① 기각.** 평균을 빼도 E가 그대로거나 오른다. μ의 기여 몫은 −0.01–0.00이고, 판독 1위 토큰도 안 바뀐다.
- **가설 ② 지지.** tuned에서 E가 크게 준다. 반복 과제(번역 불필요), lens 학습 언어(ko·zh·en vs ko·zh: Llama 0.380/0.380), 데이터셋 A·B·C 모두에서 같은 숫자가 반복된다. 즉 logit lens의 높은 E는 **번역 때문이 아니라 어떤 과제든 중간 층을 logit lens로 읽으면 생기는 현상**이다.
- **정직하게 말해야 할 점**
  - **E는 Wendler et al.의 지표와 다르다.** E는 *모든 라틴 토큰* 확률의 비중(글자 비중)이고, Wendler는 *정답 단어의 영어 번역* 확률을 본다. 그래서 "0.94 → 0.38"을 "Wendler의 영어 경유가 60% 부풀려졌다"로 말하면 안 된다. 말할 수 있는 것은 "logit lens의 중간 층 라틴 질량은 대부분 과제와 무관한 조각"까지다. Wendler 식 비교는 실험 4(단어 단위)가 맡는다.
  - tuned는 최종 출력을 따라가도록 학습돼서 판독이 최종 답 언어 쪽으로 끌릴 수 있다(반복 과제에서 한글로, 번역에서 한자로 감). 그래서 "tuned E 0.38이 진짜 값"이 아니라 **"logit E는 부풀려졌다"**까지만 주장한다.
  - EXAONE은 감소 폭이 작다(0.67 → 0.55). 차이는 20층 이후에서만 크다.

## 4. 실험 3 — 줄어드는 것은 영어 '글자'이고, 개념 특이적 영어 '단어'는 남는다

### 기대한 것
실험 2에서 tuned가 E를 줄인 것이 "영어를 아예 못 읽는 lens라서"라면 의미 있는 영어 단어 신호도 같이 사라져야 한다. 반대로 lens가 무관한 영어만 걸러 낸다면, **입력 개념에 맞는 영어 단어 신호(spec)는 tuned에서도 남아야 한다.** 이게 이 프로젝트의 핵심 주장이 될 수 있는지 보는 실험이다.

### 실제 결과

**(a) 데이터셋 A, 단어 단위** (ℳ 평균, 정답 3/4)

| | lens | gap = 영어 단어 − 정답 [CI] | **spec** = spring\|봄 − spring\|여름·가을 [CI] |
|---|---|---|---|
| Llama (43) | logit | **+2.16** [1.70, 2.61] | **+2.28** [1.96, 2.61] |
| | 평균 제거 μ_wiki | +2.31 | +2.58 |
| | tuned | −0.36 [−0.86, 0.15] | **+1.75** [1.43, 2.03] |
| EXAONE (31) | logit | +1.56 [1.17, 2.01] | +0.02 [0.01, 0.04] |
| | tuned | +0.08 [−0.51, 0.70] | +0.03 [0.01, 0.05] |

- 2/4 기준(Llama 48문항)도 거의 같다: gap 2.35 → −0.19, spec 2.30 → 1.80.

**(b) 데이터셋 C, 다의성 없는 일반 단어** (194문항, 번역)

| lens | Llama B_zh | Llama B_ko | **Llama Spec** [CI] | EXAONE B_zh | EXAONE B_ko | EXAONE Spec |
|---|---|---|---|---|---|---|
| logit | 0.14 [−0.01, 0.29] | **0.94** [0.78, 1.11] | **4.54** [4.29, 4.80] | **0.92** | **0.98** | 0.07 |
| mean_wiki | 0.21 | 0.84 | 5.20 | 1.16 | 1.11 | 0.07 |
| mean_task | 0.72 | 0.85 | 8.40 (인공적으로 부풀음) | 1.04 | 1.00 | 0.34 |
| **tuned** | **−2.25** [−2.47, −2.02] | **−0.54** [−0.76, −0.32] | **3.85** [3.59, 4.12] | 0.20 | 0.97 | 0.07 |

- B_zh = lp(culture) − lp(文化): 입력과 무관한 개념을 영어로 더 읽는 편향. 가설 ①이 설명하려던 대상.
- Llama 반복 과제(바다 → 바다): Spec logit 2.47 → tuned 2.43. 번역이 필요 없어도 거의 그대로다.
- Llama logit → tuned 변화: Δ B_zh −2.39 [−2.57, −2.22], Δ Spec −0.69 [−0.79, −0.60].

### 결론
- **Llama에서 tuned lens는 "무관한 영어"는 지우고(B_zh 0.14 → −2.25) "관련 영어"는 85% 남긴다(Spec 4.54 → 3.85).** A의 다의어에서도 같다(spec 2.28 → 1.75). 반복 과제에서도 남는다.
- 즉 **중간 층의 영어 단어는 입력 개념에 맞춰 뜨는 진짜 신호이고, lens 보정을 해도 살아남는다.** spec은 같은 토큰끼리 비교하므로 "spring이 원래 흔한 단어라서"는 상쇄된다. 이 프로젝트에서 가장 튼튼한 결과다.
- 평균 제거는 무관 영어 편향(B)을 줄이지 못한다 → C에서도 가설 ① 기각.
- **EXAONE은 해석이 어렵다.** 중간 층(8–22)에서 spec이 모든 lens에서 0.02–0.07로 거의 0이다. EXAONE의 영어 단어는 23층 이후에 뜬다. EXAONE의 무관 영어 편향 B_ko는 tuned에서도 0.97로 그대로다. 한자 바이트 조각 문제도 있다(온전한 글자 60문항만 보면 B_zh 0.92 → 0.59).

## 8. 실험 7 — 인과 개입: 중간 층의 영어 spring 방향을 지우면 무슨 일이 일어나나 (Llama)

- logit lens의 라틴 질량은 입력에 영어가 있든 없든 거의 같다. 그러므로 이 값은 내용과 무관한 판독 바닥값이고, 그 크기가 곧 부풀림의 정도다.
- 부풀림을 줄이는 lens는 tuned 하나다. affine은 판독이 무너져 판정할 수 없다.
- tuned는 두 조건 모두 최종 출력이 중국어인데도 값이 오른다. 따라서 "tuned는 출력 언어를 따라갈 뿐"이라는 반론에 어느 정도 답이 된다.

**원인 (가설)**: logit lens는 중간 층 벡터를 최종 층의 W_U로 그대로 읽기 때문에 출력층의 사전 쏠림이 나타나고, tuned의 층별 변환이 이를 없앤다. 근거는 세 가지다. 입력 내용과 무관하고, 평균(상수) 성분도 아니며, 마지막 1–2층에서야 사라진다. 이 가설을 확정하려면 다음 세 실험이 필요하다. (1) 무내용 벡터로 판독한 바닥값 측정 (2) tuned 변환을 편향만/대각/저랭크로 나누어 어느 부분이 쏠림을 지우는지 확인 (3) 부풀린 라틴 방향을 제거한 뒤 출력이 변하는지 확인.

**한계**: 층별 평균만 남아 있어 CI가 없다. Llama tuned는 13→14층에서 0.58→0.12로 급락해 7–13층이 덜 학습됐을 수 있다. EXAONE 중간 층은 어느 lens도 영어 삽입에 반응하지 않아 판정할 수 없다.

## 10. 종합 결론

### 말할 수 있는 것 / 말할 수 없는 것

| 주장 | 강도 | 근거 |
|---|---|---|
| ridge affine(MSE)은 lens로 쓸 수 없고, tuned(KL)가 가장 충실하다 | **강함** | 실험 1: KL, 언어 질량 0.996 '기타', 학습 언어 민감도 |
| logit lens의 높은 영어 글자 비중은 평균 성분 때문이 아니다 | **강함** | 실험 2·3: A·B·C, 반복 과제에서 평균 제거 효과 0 |
| logit lens의 중간 층 라틴 질량은 대부분 과제와 무관한 조각이며, 기저 차이로 부풀려진다 | **강함 (Llama)**, 중간 (EXAONE) | 실험 2: tuned에서 0.94 → 0.38, 반복·학습 언어·데이터셋 무관 |
| 중간 층의 영어 단어 신호는 입력 개념 특이적이고 tuned에서도 남는다 | **강함 (Llama)** | 실험 3: spec 2.28 → 1.75 (A), 4.54 → 3.85 (C), 반복 과제에서도 유지 |
| 영어 다의어의 다른 뜻이 최종 출력에 새어 나온다 (행동 간섭) | **중상** | 실험 5: I_adj +1.3, 양성·음성 대조 통과. placebo 정합성 ok:False |
| 중간 층 영어 spring 표상이 번역에 인과적으로 쓰인다 | **중간 (예비)** | 실험 7: 방해어 −0.52, 정답 −0.49. 직교화 확인(실험 8) 전 |
| E 감소 "0.94 → 0.38"은 Wendler et al. 결과가 그만큼 부풀려졌다는 뜻이다 | **말할 수 없음** | E는 글자 비중이고 Wendler는 번역 단어 확률. 지표가 다름 |
| tuned E 0.38이 모델의 "진짜" 영어 비중이다 | **말할 수 없음** | tuned는 최종 출력 쪽으로 끌릴 수 있음 |
| "영어가 먼저, 목표 언어는 나중" 순서가 모델의 실제 처리 순서다 | **약함** | 실험 4: tuned에서는 순서가 거의 사라짐 |
| logit lens는 영어 무관 간섭(B)과도 상관이 있고 tuned는 이를 지운다 | **약함** | 실험 6: 19문항에서만 Δ CI < 0, 늘리면 0에 걸침 |
| lens 영어 점수가 문항 간 간섭 크기를 따라간다 (예측 2) | **판단 불가** | 실험 6: 모든 r_L의 CI가 0 포함 |
| 간섭만 선택적으로 영어를 거친다 | **지지 안 됨** | 실험 7: sel ≈ 0. 탐색 상관 ρ=−0.51은 확인 필요 |

### 한 문단 요약
<img width="3800" height="1320" alt="image" src="https://github.com/user-attachments/assets/5d563b69-824a-4317-bdbb-d6ed0cfceb65" />

logit lens가 다국어 모델 중간 층에서 보여 주는 "영어"는 두 성분으로 나뉜다. 하나는 **과제와 무관한 라틴 조각**으로, 평균 성분이 아니라 중간 층과 최종 층의 기저 차이 때문에 생기며, 출력 분포로 학습한 tuned lens에서 대부분 사라진다(Llama 글자 비중 0.94 → 0.38). 다른 하나는 **입력 개념에 맞춰 뜨는 영어 단어 신호**로, 같은 토큰끼리 비교한 spec이 tuned에서도 75–85% 남고 번역이 필요 없는 반복 과제에서도 유지된다. 이 영어 표상은 행동에도 흔적을 남긴다. 영어 다의어의 다른 뜻이 최종 출력 확률을 무관 단어 대비 약 3.7배 끌어올리고, 중간 층에서 spring 방향을 지우면 정답과 방해어가 함께 떨어진다. 따라서 "모델이 속으로 영어 개념을 쓴다"는 해석의 핵심은 lens 보정 후에도 유지되지만, **영어 비중의 크기나 "영어가 먼저 온다"는 순서를 logit lens로 주장하면 과장**이다. 인과 주장은 직교화 개입(진행 중) 결과를 보고 확정한다.

- tuned lens가 30 epoch 안에 완전히 수렴하지 않았다.
